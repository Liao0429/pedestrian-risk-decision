对 H:/PedestrianRiskDecision 的板端 C++ 工程做以下 P1 优化（只改 src/luckfox_rtsp_yolov5/ 与 src/algorithms/，不要动 src/algorithms/*.py 接口）：

1. 消除 RiskEngine 与 EnhancedDecision 的重复特征计算：main.cc 每帧对同一批脚点同时跑 EnhancedDecision（内部调 graph_laplacian）和 RiskEngine 旁路，纯浪费算力。改为：增强决策默认启用时，跳过 RiskEngine 旁路的重复 computeFeatures 调用（或让 RiskEngine 复用已算出的网络特征），板端省一半特征计算。可用配置开关（如 config 加 enable_risk_engine_fallback:false）控制，默认关闭旁路。

2. 统一透视变换：main.cc 的 mapToGroundPixel() 与 risk_engine.cc 的 mapToGround() 是同一 IPM 变换的重复实现，收敛到单一实现（如抽取到公共 helper），消除第三份拷贝。

3. VLA 改 std::vector：yolov5.cc 中 `rknn_tensor_attr input_attrs[io_num.n_input]` 与 `output_attrs[io_num.n_output]` 是 C99 VLA，C++11 不允许且 io_num 可能为 0 有越界风险。改用 std::vector，并在查询后校验 n_input/n_output > 0。

4. 初始化错误检查：init_yolov5_model、vi_dev_init、venc_init、RK_MPI_SYS_Init 等初始化返回码目前多数未检查或仅 printf 后继续，失败后继续运行易崩溃。改为：任一关键初始化失败时打印明确错误并安全退出（清理已初始化资源）。

5. 统一 RiskLevel 枚举：risk_engine.h 使用 C 风格 typedef enum CrowdLevel，而增强决策用 C++ RiskLevel。main.cc 中有 `(CrowdLevel)er.level` 强转，类型不安全。统一为单一枚举（可保留 RiskLevel，删除 CrowdLevel 或让 CrowdLevel 别名指向 RiskLevel），消除强转。
