## 一、结论速览

1. **现有外壳 STL（`enclosure_lower.stl` / `enclosure_upper.stl`）存在 P0 级几何错误**：屏幕窗口（55×70mm）被开在仅 14mm 高的顶盖前面板上，几何上不可能容纳 76.5mm 高的屏幕；现有「屏幕竖插在机壳前壁外」的装配渲染图是视觉取巧，实际无法安装。**外壳必须重新建模。**
2. **`gimbal_3d.svg` / `wiring_3d.svg` 只够当概念图，不足以作为外壳设计输入**：无真实尺寸、无孔位、无舵机/屏幕/PCB 接口坐标。外壳设计前需采购后实物测量（或按本报告尺寸表建模）。
3. **推荐结构**：底座（容纳 PCB+外设）+ 背部走线腔立柱（线束垂直通道）+ 屏幕面板（前倾 75°）+ 顶部云台平台（双 SG90 外置）。
4. **推荐整机外形**：约 **140×110×190mm**（含云台最高点约 215mm），壁厚 **2mm**。
5. **固定方式**：承力/反复拆装位用 **M2.5/M3 热熔铜螺母**，一次性固定位用 **自攻螺丝**（舵机 M2 自攻、盖板 ST2.9 自攻）。

- **可用信息**：装配顺序（底座→水平舵机①→L型臂→垂直舵机②→摄像头固定座→摄像头）、Yaw/Pitch 轴系、FFC 随动走线概念。

- **可用信息**：完整连接拓扑（充电宝→DC模块→PCB→开发板→屏幕/舵机/LED/按键/USB Hub→WiFi/麦克风/喇叭），标明了线束种类（5V/3.3V/PWM/SPI/USB/GND）。

### 4.4 散热与走线约束

**散热**
- RV1106 满载（NPU 推理+RTSP）SoC 温度高，底座顶面对应开发板 SoC 正上方开 20×20mm 孔阵，并建议贴 15×15×5mm 铝散热片（BOM 增强项）。
- 底座内开发板下方必须悬空（6mm 立柱），PCB 背面铜皮散热空间 ≥4mm。
- MP1584 与喇叭不要贴死：MP1584 周围留 5mm 空气隙；USB 喇叭背面留后腔（容积≥喇叭振膜后腔体积的 1/3），否则声音发闷。

**走线**
- 背部走线腔深 10mm：FFC 弯曲半径 ≥5mm（0.5mm 间距 FFC 允许最小弯折半径约 2mm），腔内用扎带耳分段固定。
- 舵机 5V 电源线与 PWM 信号线**分束**（左右分开走），避免长距离并行走线引入干扰。
- 云台 FFC 从顶部过线槽垂直入腔，**留 30~50mm 松弛量**再固定，防止云台转动拉扯排线。
- 屏幕排线/FFC 从面板背面直接入腔下到底座，路径上无锐边（过线槽倒 R1 圆角）。

## 五、装配顺序与固定方式

### 5.1 固定方式选型

| 位置 | 推荐固定 | 理由 |
|---|---|---|
| PCB ↔ 底座 | **M3 热熔铜螺母 + M3×8 沉头螺钉** | 承力、可能多次拆装；铜螺母外径 4.0mm，需 φ7mm 凸台 |
| 屏幕 ↔ 面板 | **M2.5 热熔铜螺母 + M2.5×6 盘头螺钉**（4 点） | 屏幕需调整/返工，拆装频繁；M2.5 铜螺母外径 3.5mm，凸台 φ6mm |
| 云台平台 ↔ 顶板 | 一体打印（平台与背板一体）或 4×ST2.9 自攻 | 非承力，一次性 |
| Yaw 舵机 ↔ 云台平台 | **M2 自攻螺丝 ×4**（SG90 底孔 φ1.8） | 舵机孔小，无法装铜螺母；平台厚 4mm 保证吃牙 |
| 云台支架套件内 L 臂/舵盘 | 套件自带螺丝 | 按套件说明 |
| 背腔盖板 | ST2.9×6 自攻 ×4 | 需要时可拆 |
| 摄像头 ↔ 云台固定座 | 3M 双面胶 + 扎带（勿用重螺丝） | SG90 扭矩小，必须轻量化（系统集成文档明确要求） |

> **热熔铜螺母注意事项**：2mm 壁厚不能直接压入，必须在安装面设计 φ6~7mm 凸台（高 ≥ 螺母长 4mm）；压入方向从安装面垂直压入，烙铁温度 220~250°C。

### 5.2 装配顺序（10 步）

1. **打印**：底座+背板+面板一体打印或分件打印 → 检查打印质量、清理支撑。
2. **压铜螺母**：底座 4×M3、面板背面 4×M2.5、（可选）云台平台 2×M2.5。
3. **PCB 固定**：把已焊接完成的 100×80 PCB 放入底座，M3×8 螺钉固定 4 角（USB-C/网口朝左）。
4. **插开发板**：Luckfox Pico Max 插入 40pin 排母，确认 USB-C/网口对准左侧开孔。
5. **装内设**：MP1584、USB Hub、USB 喇叭固定到底座内；Type-C、电源开关、按键、LED 先装入侧壁/面板孔位再焊接/接线；Hub 上行口接开发板 USB Host。
6. **装屏幕**：屏幕排线先穿走线腔，从面板背面装入开窗，M2.5×6 固定 4 点；排线沿腔内固定到底座 PCB。
7. **装云台**：顶部平台装 Yaw 舵机（M2 自攻）→ 舵盘 → L 臂 → Pitch 舵机 → 摄像头固定座 → SC3336 摄像头；FFC 从顶部过线槽穿入走线腔接开发板 MIPI；舵机线穿 φ6 孔接 PCB J3/J4。
8. **接外设**：RTL8723BU 插 Hub、USB 麦克风（可立装于顶部侧面小支架）；喇叭线/USB 归位。
9. **封背腔**：整理线束（扎带固定），扣上背腔盖板。
10. **上电自检**：跑 `make hardware-selftest`（6 项 PASS/FAIL），再跑 `scripts/start_demo.sh`。

### 5.3 材料与打印参数建议

- 材料：**PLA+ 或 PETG**（PETG 更耐热、韧性好，适合外壳）；壁厚 2mm，层高 0.2mm，填充 20% gyroid；云台平台 4mm 用 40% 填充。
- 打印方向：底座开口朝上；背板/面板竖放（层线与受力方向垂直更不易裂）。
- 支撑：屏幕窗口背面、走线腔顶部需支撑；面板 75° 倾角建议分件打印避免大面积悬挑。
