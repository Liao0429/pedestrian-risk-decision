## 质疑点 2：『离线实验与生产流水线差 911 帧未解释』定【高】严重度 — 归因错误，实验设置不同本就正常

**质疑**：A7 称「`_spectral_fsm_experiment.json` 的 M1_0.1（12659 帧/68 条）与 README 生产口径（11748 帧/66 条）差 911 帧未解释，脚本 M0 一致性仅 89.67% 说明『离线重算与生产实时推理天然存在 ~10% 帧级偏差』」。交叉复算后，**A7 对 89.67% 的归因是错的，911 帧的成因也不是「离线 vs 在线」**：

1. **M0 一致性 89.67% 度量的是「谱特征有无」，不是「离线 vs 在线」**。脚本 `run_videos()` 的一致性校验用 `replay(tl, cfg, "M0", 0.0, ...)`，即 `w4=0`（无谱特征）的等级序列去对比生产时间线——而生产时间线是**含谱特征（w4=0.1）**的规范结果。本报告独立复现：`M0(w4=0) 一致率 = 89.6737%（40372/45021）`，与 A7 一致；但用**生产配置（w4=0.1）**离线回放，一致率高达 **98.2097%（44215/45021）**。也就是说，离线回放流程本身与生产推理的帧级一致率约 98.2%，真实离线/在线偏差仅 ~1.8%；89.67% 与 98.21% 之间约 8.5 个百分点的差距，正是「谱特征项接入与否」造成的帧级变化。
2. **911 帧差异的真正来源是公式不同，属实验设计使然**。M1 的谱修正为 `score += w4 * fiedler_norm`（所有 fiedler>0 的帧都加分，无门控）；生产公式为 `score += w4 * fiedler_norm * r_gcc`（仅 `r_gcc>0 且 fiedler>0` 生效，见 `risk_fsm.py::_compute_score`）。M1 是扫描「纯谱正反馈」的**实验模式**，本就不应与生产口径一致——拿 M1_0.1 与生产 11748 比差 911 帧，类似拿消融 C 组与生产比差异，属于口径错配的伪问题。真正同口径的对比（M0 无谱 vs 历史生产无谱 7807）只差 99 帧（见质疑点 1）。
3. **A7 的建议方向仍然可取，但理由需更正**：README/结果文件确实应说明「离线实验 M1/M2 是独立实验公式，与生产谱修正公式不同」，但这不是「~10% 帧级偏差」需要解释的问题。

**判断**：严重度应下调为【中】或【低】。核心事实（数字真实、可复现、口径差异可解释）没有被撼动；被质疑的是「README 未主动解释离线实验与生产口径的关系」这一**文档完善问题**，而非数据矛盾。A7 将「未解释」与「数据不可信」挂钩并定【高】，评级依据不成立。

**建议**：
- A7 报告更正归因：89.67% 是「无谱 vs 有谱」的一致率，不是离线/在线偏差；离线/在线偏差实测 ~1.8%；
- 在 `_spectral_fsm_experiment.json` 的 `method` 字段或 README 加一行：「M1/M2 为实验谱修正公式（M1 无 r_gcc 门控），与生产公式 `score += w4·fiedler/(fiedler+1)·r_gcc` 不同，M1_0.1 的 12659 帧不能与生产 11748 直接对比」；
- 该条严重度降为【中】（口径标注缺失）。

## 质疑点 3：『Spearman ρ=0.688 是构造性相关』 — 方向对（显著性表述应弱化），但机制论证错误，且不构成数据缺陷

**质疑**：A7 称「fiedler 本身就是 FSM 评分输入（w4 项），等级是评分的函数，两者相关部分由构造决定」，建议弱化为「描述性相关」。交叉复算后，**A7 的机制论证不成立，但其「弱化表述」的结论仍然正确**：

1. **ρ=0.688 的主体不是「评分函数同源」**。本报告用「无谱配置（w4=0，fiedler 完全不参与评分）」的 M0 等级序列与 fiedler 计算 Spearman：**ρ = 0.6988，反而高于生产等级（含 w4 项）的 0.6882**。如果 ρ 是由「fiedler 作为评分输入、输出与输入同源」构造出来的，去掉 w4 项后 ρ 应大幅下降，而实测不降反升。真正的原因是：**fiedler 与 FSM 评分的主特征高度共线**——fiedler vs density ρ=0.8049、vs r_gcc ρ=0.773、vs n ρ=0.4315，而等级主要由 density（ρ=0.7806）和 r_gcc（ρ=0.7598）决定。ρ=0.688 反映的是「谱连通度与聚集密度/连通占比的几何共变」，这是一种真实的数据关系，不是评分函数的循环论证。
2. **w4 谱项的独立贡献是可分离且较小的**：在 fiedler>0 的 10814 帧内，M0 等级 vs fiedler 的 ρ=0.0929，生产等级 vs fiedler 的 ρ=0.3503——w4 项带来的增量相关约 **0.26**。这与消融 D vs C 的 +152 帧（WARNING→DANGER 重分类）互相印证：谱修正项确实存在真实的（中等强度的）增量作用，但全量 ρ=0.688 远不能归因于它。
3. **A7 与 R8 都指出的「帧间非独立导致 p 值无意义」是对的，且有更硬的数据支持**：按视频聚合（每条视频一个 Spearman）后，111 条视频的 ρ 均值为 **0.2273**、中位数 0.1959（75 条为正、5 条为负、31 条为 0——即 31 条全程 SAFE 无变化）。全量 0.688 主要来自「跨视频组间差异」（fiedler 全为 0 的 SAFE 视频 vs fiedler 高的 DANGER 视频），视频内部的逐帧单调关系弱得多。README 的「显著正相关」在统计意义上是站不住的。

**判断**：A7 的「构造性相关」质疑**方向成立但机制错误**——不是「输入-输出同源构造」，而是「fiedler 与评分主特征共线 + 跨视频组间差异」。更重要的是，该质疑 **不构成数据缺陷**：ρ=0.688 是真实数据关系，只是被过度解读为「显著/因果」。fiedler 作为 FSM 评分输入（w4 项）确实与风险等级同源（用户质疑点③），但「同源」不等于「编造」或「无信息量」——共线本身也是数据事实，且 w4 项有可分离的增量贡献（消融 +152 帧实证）。此条严重度应为【低】（表述严谨性问题），而非数据可信度问题。

**建议**：
- 接受 A7/R8 的「弱化显著表述」建议，但把论证改为：「ρ=0.688 主要反映 fiedler 与 density/r_gcc 的共线关系；帧间非独立、按视频聚合后 ρ 均值仅 0.23，不宜宣称统计显著；建议表述为『描述性正相关』」；
- 论文可正面利用本报告的分离结果：在 fiedler>0 帧内 w4 项提供约 0.26 的增量相关（生产 0.35 vs 无谱 0.09），配合消融 +152 帧，作为「谱特征提升高风险识别灵敏度」的量化证据；
- 建议 A7 报告补充按视频聚合的 Spearman（mean 0.2273 / median 0.1959）作为其质疑的实证支撑，而不是停留在「构造性」的定性判断。

## 质疑点 4：A7 复现验证方法有漏洞 — 数字复现扎实，但存在 5 处方法性盲区

**质疑**：A7 的复现工作整体质量高（图片 GT 500/500、聚合 identical=True、Spearman 0.6882 等均已独立验证，本报告复算全部吻合），但其验证方法存在以下盲区：

1. **未查 git 历史就断言「7807 无存档」**。`git log -S 7807` / `git show a92e4a5:results/rerun/_comparison_summary.json` 即可发现历史存档（enh_lv DANGER=7807）。对「历史数字是否可追溯」类问题，git 历史是仓库内的一等证据源，A7 的复现流程缺少这一环节。

**仍未验证的数字清单（截至本报告）**：

## 最高价值质疑（Top 3-5）

1. **【严重度高估】7807「无存档」在 git 历史中不成立**：`a92e4a5` 提交的 `_comparison_summary.json` 明确存档 `enh_lv DANGER=7807`（enh_danger=40），README 历史版/工作日志/6+ 份 review 文档均有记录；离线 M0=7906 与 7807 仅差 1.27% 且 DANGER 视频数 40=40 完全一致。A7 的【高】应降为【中/低】，且「仅工作日志提及」的说法需更正为「README 与 git 历史均有，当前工作区无该历史聚合 JSON」。

2. **【归因错误】89.67% 不是「离线 vs 在线 ~10% 偏差」**：实测生产配置（w4=0.1）离线回放一致率 **98.21%**，89.67% 与 98.21% 的差就是「谱特征有无」的帧级变化。离线/在线真实偏差仅 ~1.8%。A7 基于该错误归因将「911 帧未解释」定为【高】不成立。

3. **【伪问题】911 帧差异源于实验公式不同，实验设置不同本就正常**：M1 是 `score += w4·fiedler_norm`（无 r_gcc 门控），生产是 `score += w4·fiedler_norm·r_gcc`。拿 M1_0.1（12659）对比生产（11748）是口径错配，不是数据矛盾；在 README/JSON 加一行公式差异说明即可，无需「解释 911 帧」。

4. **【机制错误但结论正确】Spearman 构造性质疑的论证要换**：无谱等级与 fiedler 的 ρ=0.6988 反而高于生产等级 0.6882，说明 ρ 主体是「fiedler 与 density/r_gcc 共线」，不是「评分函数输入-输出同源」；按视频聚合后 ρ 均值仅 0.2273。「显著正相关」表述确实应弱化，但理由是帧非独立 + 共线 + 组间差异，而非 A7 给出的「同源构造」。这不是数据缺陷，且 w4 项在 fiedler>0 帧内有 ~0.26 的增量相关可作论文正面论据。

5. **【方法漏洞】A7 的两条高严重度评级都建立在「未查 git 历史 + 未审查脚本语义」之上**：数字复现扎实，但复现输出≠理解语义；tiny_gt 的 13.5% 与 r=-0.403 至今无独立复核。建议 A7 修订报告时补充 git 历史检索与 `m0_spectral=True` 回放验证。
