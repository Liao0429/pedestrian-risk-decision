## 一、总体结论

**当前版本不可投板。** 独立 DRC 与 Gerber 逐条核对发现 **6 类共 14 处跨层/同层短路（P0）**，全部集中在电源网络（VIN/5V/5V_SERVO）与 GND 之间，以及屏幕 SPI 信号线，属于"上电即短路/功能全废"级别的缺陷。软件自带 DRC 输出"✅ DRC 全部通过：无短路、无断连"**结论不成立**——其检查逻辑存在 3 个盲区（见 P0 根因）。

同时确认了以下**正确项**：98 焊盘/19 走线/14 过孔计数一致；J2a/J2b/J3/J4/J5/J6/J11/J10A/J10B/U1 全部为 2.54mm 间距；钻孔文件 116 孔（98 焊盘 + 14 过孔 + 4 个 M3 孔）分类正确；SPI 引脚映射 MOSI=Pin15/MISO=Pin16/CS=Pin12/SCLK=Pin14 与 J11 网络一致；PCB 四角 M3 孔 (5,5)/(95,5)/(5,75)/(95,75) 与外壳底座 4×M3 铜螺母柱 (25,20)/(115,20)/(25,90)/(115,90) 完全对齐；外壳五件套装配干涉检测无干涉；F3 终检已修的折边孔/穿线孔/FOV/屏开孔对齐验证通过。

**建议：先修复全部 P0 短路并重跑本报告附录的独立 DRC，再安排投板；投板前按 P1 逐项实测确认。**

## 二、P0 问题（阻断投板，必须修复）

### P0-1：VIN / 5V 电源轨与 GND 短路（最严重，上电即短路）
- **现象**：底层 GND 走线 `(68,8)→(90.08,8)`（线宽 0.8mm，B 层）正好从电源输入排针 J1-1、电源开关 SW1-1/SW1-2 的通孔焊盘中心穿过。通孔焊盘的镀铜孔壁与 B 层 GND 走线接触，导致：
  - J1-1（VIN）↔ GND 短路（generate_pcb.py:36 `add_pad("J1-1",85.0,8.0,"VIN",1.2,1.0)`）；
  - SW1-1（VIN）↔ GND 短路（generate_pcb.py:38）；
  - SW1-2（5V）↔ GND 短路（generate_pcb.py:38）。
- **证据**：
  - `PedestrianRisk_B.Cu.gbl` 第 20 行：`X0068000000Y0008000000D02* X0090080000Y0008000000D01*`（GND 走线 y=8 横穿 J1/SW1 焊盘行）；
  - `PedestrianRisk.drl` T03/T04 显示 J1/SW1 为通孔（1.2/1.0mm 镀孔）；
  - generate_pcb.py:131 `add_trace("GND",[(68,8),(90.08,8)],W_GND, layer="B")  # C2- -> J1-2`。
- **根因**：DRC 的"线段 vs 异网络焊盘"检查（generate_pcb.py:206-207）要求焊盘铜必须在走线层上才检查；J1/SW1 焊盘仅 T 层，B 层走线从孔下穿过被跳过，但镀通孔孔壁实际把两层连通。
- **修复建议**：B 层 GND 走线不得从任何非 GND 通孔焊盘下方穿过。将 `(68,8)→(90.08,8)` 改为在 y=12（或 10）走线，仅通过过孔/焊盘环连接到 J1-2 与 C2-2（GND），避开 J1-1/SW1 位置。修复后用附录独立 DRC 重查。

### P0-2：5V_SERVO 舵机电源轨与 GND 短路
- **现象**：底层 GND 走线 `(85,24)→(85,28)→(70.5,28)→(70.5,24)→(90.08,24)`（generate_pcb.py:130）：
  - 起点 (85,24) 恰为 J2b-1（5V_SERVO）焊盘中心（generate_pcb.py:41）→ 5V_SERVO ↔ GND 短路；
  - 水平段 (85,28)→(70.5,28) 穿过 C1+（74,28，5V_SERVO）焊盘（generate_pcb.py:43）→ C1+ ↔ GND 短路。
- **证据**：`PedestrianRisk_B.Cu.gbl`：`X0085000000Y0024000000D02* X0085000000Y0028000000D01* ... X0074000000Y0028000000D01*`；`PedestrianRisk_F.Cu.gtl` 在 (85,24)/(74,28) 有 5V_SERVO 焊盘 D03。
- **修复建议**：GND 回路由 J2b-2（85,26.54）焊盘环接出即可，去掉伸到 J2b-1 的 (85,24) 端点；水平段从 y=26 以下（避开 C1+ 焊盘）或绕行 C1+ 外侧。

### P0-3：J10A 跳线区 7 个信号脚全部与 GND 短路
- **现象**：底层 GND 走线 `(76.54,60)→(76.54,64)→(52.54,64)→(52.54,70)`（generate_pcb.py:133，注释"J5GND->J6GND"）的 y=64 水平段正好沿 J10A 排针行穿过。J10A 焊盘位于 y=64（generate_pcb.py:68-76），其中 x=52.54(TILT_SIG)/55.08(VOICE_TX)/57.62(VOICE_RX)/60.16(SCREEN_TX)/62.70(SCREEN_RX)/65.24(SW_ALARM)/67.78(BUSY) 全部落在该走线上 → **7 个跳线信号全部与 GND 短路**（仅 x=50 的 PAN_SIG 未被穿到）。跳线区（J10A/J10B）是"无需飞线切换开发板 GPIO"的核心功能，此缺陷使其完全失效。
- **证据**：`PedestrianRisk_B.Cu.gbl`：`X0076540000Y0060000000D02* X0076540000Y0064000000D01* X0052540000Y0064000000D01*`；`PedestrianRisk_F.Cu.gtl` 在 y=64 有 J10A 8 个焊盘 D03。
- **修复建议**：将 J5GND→J6GND 的 B 层走线改道，避开 y=64（例如 y=62 或 y=66），或从 J10A 行左侧 x<50 绕行；J6-GND (52.54,70) 的连接改为在 x=52.54 从 y=66 下行接入。

### P0-4：J11 触摸屏 SPI_RST 与 GND 短路
- **现象**：底层 GND 走线 `(76.54,60)→(76.54,56)→(90.08,56)`（generate_pcb.py:135）的水平段 y=56 穿过 J11-SPI_RST 焊盘 (77.78,56)（generate_pcb.py:64-67）→ **SPI_RST ↔ GND 短路**。
- **证据**：`PedestrianRisk_B.Cu.gbl`：`X0076540000Y0056000000D01* X0090080000Y0056000000D01*`；`PedestrianRisk_F.Cu.gtl`：`X0077780000Y0056000000D03*`。
- **修复建议**：该段 GND 走线从 y=58（J11 行下方 2mm）走，或在 x=76.54 处直接下钻到右竖干，避免穿过 J11 行。

### P0-5：喇叭负极 SPK_N 与 GND 短路
- **现象**：B 层 GND 右竖干 `(90.08,8)→(90.08,62)`（generate_pcb.py:128）终点 (90.08,62) 恰为 J7-2（SPK_N）焊盘（generate_pcb.py:59）；且 GND 过孔列表中含 (90.08,62)（generate_pcb.py:143-146），过孔直接打在 SPK_N 焊盘中心 → **SPK_N ↔ GND 短路**。
- **证据**：`PedestrianRisk_B.Cu.gbl`：`X0090080000Y0008000000D02* X0090080000Y0062000000D01*` 及 `X0090080000Y0062000000D03*`（过孔）；`PedestrianRisk_F.Cu.gtl`：`X0090080000Y0062000000D03*`（J7-2 焊盘）。
- **修复建议**：右竖干 GND 止于 J5-GND 分支即可（J7 是喇叭，无需 GND 接入），删除 (90.08,60)→(90.08,62) 段与 (90.08,62) 处的 GND 过孔。

### P0-6：J11 触摸屏 SPI_CS / SPI_DC 与 5V_SERVO 短路（同层）
- **现象**：顶层 5V_SERVO 走线 `(87.54,46)→(87.54,54)→(74,54)→(74,60)`（generate_pcb.py:100）的 x=74 垂直段从 J11 行 (y=56) 穿过。J11-SPI_CS 在 (72.7,56)、J11-SPI_DC 在 (75.24,56)（generate_pcb.py:64-67），两焊盘间距 2.54mm、半径 0.8mm，焊盘边缘间隙仅 0.94mm；走线宽 1.0mm，无法通过该间隙：
  - 走线左边缘 x=73.5 与 SPI_CS 右边缘 x=73.5 **刚好相切（净距 0.00mm）**；
  - 走线右边缘 x=74.5 与 SPI_DC 左边缘 x=74.44 **重叠 0.06mm**。
  → **SPI_CS / SPI_DC 与 5V_SERVO 短路**。
- **证据**：`PedestrianRisk_F.Cu.gtl`：`X0087540000Y0054000000D01* X0074000000Y0054000000D01* X0074000000Y0060000000D01*`；`X0072700000Y0056000000D03*`、`X0075240000Y0056000000D03*`。
- **修复建议**：5V_SERVO→J5-VCC 的走线改道（例如沿 y=54 延伸到 x=62 左侧，再从左侧下行到 J5-VCC；或走 B 层），不得从 J11 排针行中间穿过。若必须穿越，线宽 ≤0.3mm 且居中，但 0.94mm 间隙下仍不推荐。

### P0 根因（软件 DRC 三个盲区，必须一起修）
1. **跨层漏检**：generate_pcb.py:206-207 只在焊盘铜位于走线同层时才检查，未建模"镀通孔（PTH）孔壁跨层导通"——P0-1/2/3/4/5 全部因此漏检。
2. **忽略线宽**：generate_pcb.py:178 `r = pad["pr"] + clear`，`segment_pad_touch` 只按焊盘半径+0.05mm 判断，未加走线半宽（`trace_segments` 已算出 w，但第 208 行调用时没用上）——P0-6（中心距 1.24mm > 0.85mm 阈值）因此漏检。
3. **无过孔 vs 焊盘检查**：整个 run_drc 没有"过孔与异网络焊盘重叠"检查——P0-5 因此漏检。
修复建议：为 run_drc 增加"THT 焊盘孔壁与异层走线/过孔"接触检查（把 drill>0 的焊盘视为双面节点，接触半径取 `max(pr, drill/2)`）；`segment_pad_touch` 半径改为 `pad["pr"] + w + clear`；新增过孔-焊盘异网络重叠检查。

## 三、P1 问题（建议投板前确认/修复）

### P1-1：外壳底座"开发板 USB-C / 网口"开孔位置与开发板实际安装位置不匹配（未验证）
- **证据**：generate_enclosure_v2.py 底座开孔：左侧壁"开发板 USB-C 调试口"中心 (1,86,12)（10×8）、"开发板网口"中心 (1,60,12)（16×14）。而 v2 中开发板通过 U1 40pin 排母插在 PCB 上，U1 位于 PCB 坐标 (10..58.26, 34..36.54)（generate_pcb.py:82-83），换算到底座坐标 (30..78.26, 49..51.54)；按自身渲染脚本（generate_3d_assets.py:153-155：开发板 60×38mm，底面 z=20.1）开发板端口高度约 z≈20-22、y≈50。开孔 y=60/86、z=8..16 与开发板端口（y≈50、z≈20）偏差约 10-36mm。
- **影响**：开发板 USB/网口无法从外壳侧壁直接插拔/接线，USB Hub 线缆需绕行。
- **建议**：实测 Luckfox Pico Max 端口位置（含排母高度），重新定位底座侧壁开孔，或把开孔改为通用过线孔并在开发板侧留出线槽。**未验证**：开发板端口精确坐标未实测。

### P1-2：摄像头 MIPI FFC 无穿线通道（未验证）
- **证据**：底座顶板 z=28..30 为封闭平面，仅 φ3 散热孔且避开 PCB 区（generate_enclosure_v2.py:88-91）；底座后壁（y=108..110）无开孔；背板走线腔唯一的底部入口是屏幕排线穿线孔（x=64..76, y=109.5..112.5, z=30..40，generate_enclosure_v2.py:157-159）。开发板 MIPI 接口在底座内 z≈21，摄像头在云台（z=190），FFC 无法从底座内部进入背板走线腔到达云台 FFC 过线槽（generate_enclosure_v2.py:200-201）。
- **建议**：在底座顶板或后壁增加 20×6mm 左右的 FFC 过线槽（避开 PCB 与螺柱），或复用/加大背板底部穿线孔并在底座后壁对应位置开孔。**未验证**：开发板 MIPI 接口实际朝向与 FFC 走线路径未实物确认。

### P1-3：5V_SERVO 走线与 J2b-2（GND）净距仅 0.16mm
- **证据**：顶层 5V_SERVO 走线 `(87.54,28)→(74,28)`（generate_pcb.py:98，线宽 1.0）在 x=85 处距 J2b-2 焊盘中心 (85,26.54) 为 1.46mm，扣除线半宽 0.5 + 焊盘半径 0.8 后净距 **0.16mm**。嘉立创经济打样常规最小线距 0.15-0.2mm，处于临界值，工艺波动可能被判短路或蚀刻不良。
- **建议**：该段下移/上移到 y=30 或 y=26 以下，留出 ≥0.3mm 净距。

## 七、附录：独立 DRC 复现方法

```python
# 关键：把 drill>0 的 THT 焊盘视为 T/B 双层节点（孔壁半径 drill/2），
# 对每条走线求线段到焊盘中心距离 d，
# 若 d - 线宽/2 - max(pr, drill/2) < 0.02 且网络不同，即为短路。
# 对 design.json 全量扫描可复现全部 14 处短路；再对过孔逐一做同样检查。
```
