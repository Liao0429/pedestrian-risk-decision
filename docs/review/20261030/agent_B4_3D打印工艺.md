## 一、总体结论

**5 件 STL 网格质量本身合格**（全部水密、环绕一致、无退化面、无非流形边），装配 **10/10 零干涉**复现成功。但本次独立评审发现 **3 个 P0 级几何功能缺陷**，均未在现有验证中暴露：

1. 前面板 **53×79 屏幕窗口实际未切穿**——布尔求差静默失败，STL 面板近乎实心；
2. 屏幕排线过槽 **被折边堵死、不贯通**；
3. 底座是**封闭箱体（顶板封死）**，PCB 无法装入。

前两项的根因是 `round_rect_hole` 用 box+4 圆柱 `concatenate` 拼出自交网格，布尔引擎无法正确求差；第三项是设计意图错误（内腔留 2mm 顶板）。现有 `verify_alignment.py` 使用 `trimesh.contains` 做探针判定，在布尔失败产生的退化网格上出现**假"空区"**（z=50 处一条 53mm 宽退化细缝被误判为窗口），导致 F3 复验"通过"的结论不可信。

另发现打印工艺类问题：底座实际**无法免支撑**（封闭顶板底面+后沿底台悬挑约 16,700mm² 需支撑）、FDM 公差下装配间隙过紧（0.1mm 单边）、背板定位孔开在 2mm 前壁上径向约束不足、耗材/成本估算偏低等 P1/P2 若干。

## 二、P0 问题（阻断打印/装配/功能）

### P0-1 前面板 53×79 屏幕窗口实际未切穿（布尔差静默失败）

**证据**（独立脚本输出）：
```
enclosure_v2_front_panel.stl: 体积=24539.8mm³ 面数=92 水密=True 欧拉=0
沿 y 射线网格扫描（x=-60..60 步2, z=0..94 步2）：
z= 0..6 : 仅 M2.5 槽 x=±48..52 穿透
z=50    : 一行 53mm 宽"空"（退化细缝，布尔失败残留）
其余 z 全部实体 → 53×79 窗口未切穿
```
- 若窗口正确切穿，面板体积应 ≈ 14,140mm³（面板 22,800 + 折边 2,400 − 窗口 10,468 − 过槽 240 − M2.5 孔 353）；实测 **24,539.8mm³**，只少了约 660mm³（≈ 过槽+M2.5 孔），窗口几乎完全未去除。
- 最小复现（`round_rect_hole(53,79,2.5,(0,0,49.5),r=2)`）：
```
round_rect_hole 体: 水密=True  体积=10592.4  面数=524
面板原体积: 22800.0
panel.difference(hole) 后体积: 22535.0  ← 只减掉 265（理论应减 10468）
对照组(纯box挖窗)体积: 14426.0          ← 正常
```
- 关闭 `trimesh.boolean.engines=["manifold3d"]` 用默认引擎结果相同（22,535），排除引擎选择问题。
- **根因**：`generate_enclosure_v2.py:41-52` 的 `round_rect_hole` 把 box 与 4 个圆柱 `trimesh.util.concatenate` 拼合，网格自交（内部面交叉），布尔库无法正确求差并**静默返回错误结果**（不报错、不抛异常）。
- 渲染图 `PedestrianRisk_外壳V2_装配.png` 中前面板只有一个细长横槽（排线槽残留），无 53×79 大窗口，与网格分析一致。
- **后果**：按当前 STL 打印，屏幕被实心面板遮挡，完全不可见。
- **修复建议**：不用拼合体做布尔。改为：① 生成单一流形圆角矩形体（如用 2D 圆角矩形轮廓 `trimesh.creation.extrude_polygon`）；② 或先用纯 box 挖 53×79 直角窗（已验证正常），再在角部补 R2 倒角；③ 生成后必须用**沿面板法向的穿透射线**验证（窗口区域全部 0 命中），不能依赖 `contains`。

### P0-2 屏幕排线过槽被折边堵死（不贯通）

**证据**：
```
按代码顺序 切过槽→并折边：体积 25040；射线 (0,z=4/6/8) 沿 y 均命中 2 次 → 不通
即使 先并折边→再切槽：体积 25000；射线 (0,z=4/6/8) 仍命中 2 次 → 不通
```
- **根因**：`generate_enclosure_v2.py:178` 过槽 `box((10, T+1=3, 8))` 深 3mm，只够切穿 2mm 面板；但折边（:181，`box((120,2,10))` 在 y=-3..-1）与面板底部叠加后总厚 **4mm**，过槽留下 **1.5mm 背壁**。无论先切后并还是先并后切，过槽都不贯通。
- 现有 `verify_alignment.py` 对 `(70,107,z 30..43)` 用 `contains` 判"槽/空"，是退化网格边界假象（过槽前腔开放、背壁封闭，射线法判定点在实体外），**实际排线无法从面板穿到背板腔**。
- **后果**：屏幕排线无法走通 P1-8 设计的路径。
- **修复建议**：过槽深度改为 ≥5mm（`T+3`，切穿面板+折边并留 0.5mm 余量），或在折边对应位置单独开 10×8 过槽；修后用射线穿透法验证。

### P0-3 底座为封闭箱体，PCB 无法装入

**证据**：
```
z=29.5 顶板层采样 396 点：实体内部 393 / 外部(孔) 3   ← 顶板基本封死
从上方射线首命中：z=30 命中 393 条（封闭顶板），z=2.5 命中 3 条（穿过散热孔到地板）
法向朝上(+Z)的面面积合计=32319.6mm²（外顶板≈15400 + 内腔顶面≈14416 + 后沿底台≈2254）
```
- **根因**：`generate_enclosure_v2.py:60-62` 内腔高度 `H - BASE_FLOOR - WALL = 25.5`，顶部留下 2mm 顶板；`lower.difference(inner)` 后箱体六面封闭，仅侧壁/顶面小孔（Type-C、USB、网口、散热孔、按键、LED）。
- **后果**：
  1. 100×80 PCB 需从上方放入内腔并锁 4×M3 铜柱（:64-78），但**不存在大于 PCB 的开口**，无法安装；
  2. 打印时内腔顶板底面是 **14,416mm² 水平悬空面**，必须加支撑，且支撑被封在箱体内部**无法取出**——与装配验证报告"底座可免支撑"直接矛盾。
- **修复建议**：内腔高度改 `H - BASE_FLOOR`（27.5mm，顶部全开），PCB 自上装入；散热孔阵列移至侧壁或改为独立顶盖（第 6 个零件）；或把顶板做成可拆卡扣件。

## 三、P1 问题（重要，影响打印/装配质量）

### P1-1 底座打印无法"免支撑"：约 16,700mm² 悬空面

- **证据**：悬空面分析 `lower 严重悬垂(<45°)=32319.6mm² (35.6%)`；扣除贴床底面 15,400mm² 后，**顶板底面 14,416mm² + 后沿底台底面 2,254mm² ≈ 16,670mm²** 为真实需支撑区。后沿底台（`generate_enclosure_v2.py:110-114`，140×16.1×2.1mm）自后壁（y=110）向外**悬挑 16.1mm**，底面朝下。
- 与 `装配验证报告.md` 第五节"底座/盖板可免支撑"矛盾。
- **修复建议**：P0-3 开口后顶板悬空面消失；底台改为与后壁一体成型的 L 形斜撑（45° 斜角），或底台朝下打印（翻转后底台贴床）。

### P1-2 FDM 公差下装配间隙过紧（0.1mm 单边）

- **证据**：
  - 折边槽宽 4.2 vs 背板螺柱 φ4.0 → **单边 0.1mm**（`generate_enclosure_v2.py:146-151, 189`）
  - 定位销 φ3.0 vs 背板孔 φ3.2 → **单边 0.1mm**（:155, :216）
  - 实测：螺柱直径≈φ4.0（z=3.5 处弦宽 2.6 与 r=2 圆柱一致）、折边槽空区宽≈4.0~4.2、定位销≈φ2.8（边界容差内）
- FDM 典型尺寸公差 ±0.2~0.3mm；0.1mm 单边间隙在 15° 斜插装配中极易卡死或压裂薄壁。
- **修复建议**：折边槽加宽至 4.8~5.0mm；定位孔加至 φ3.5；螺柱可选 φ3.6。在装配验证中加入"配合间隙 ≥0.3mm"的自动检查。

### P1-3 背板定位孔开在 2mm 前壁上，径向约束不足

- **证据**：定位孔 φ3.2 位于 2mm 前壁（y=110..112）正中（:155），孔直径大于壁厚，实际是**两面开口的 U 形槽**；云台定位销（φ3×6mm）只有中间 2mm 被径向约束，其余 4mm 悬空，云台可绕 x 轴晃动。
- **修复建议**：背板前壁顶部局部加厚 6mm 凸台再打 φ3.2 盲孔；或把销孔做成通孔并在腔内加导向环。

## 四、P2 问题（低危/建议）

### P2-1 底座 M3 铜柱孔 φ3.2 与紧固方式不匹配
- 热熔铜螺母 M3 需底孔 **φ3.8~4.0**；直接自攻需 **φ2.5~2.8**；当前 φ3.2 两者都不适配（`generate_enclosure_v2.py:76`）。若按"铜螺母柱"采购热熔嵌件，孔必须扩大。
- 建议：明确选型后改孔（热熔嵌件 φ3.9×深 6mm，或自攻 φ2.6）。

### P2-2 云台 M2 自攻孔 φ2.0 偏大
- M2 自攻底孔宜 φ1.6~1.8；φ2.0 接近间隙孔，螺丝易滑丝（:208）。
- 建议：改 φ1.7 或改用 M2 热熔嵌件。

### P2-3 耗材/成本估算偏低
- 5 件体积合计 96,726+85,678+24,540+19,442+38,400 = **264,786mm³**；PLA 密度 1.24g/cm³ → **328g（不含支撑）**。报告称"~267g（含 20% 支撑废料）"，实际约 328g + 20% 支撑 ≈ **394g**；按 22.7 元/267g 单价折算约 **33.5 元**而非 22.7 元。
- 建议：更新 `装配验证报告.md` 第五节估算。

### P2-4 排线槽/穿线孔宽度可能容不下 24P 0.5mm FFC
- 面板过槽宽 10mm（:178）、背板穿线孔宽 12mm（:160）；24P 0.5mm FFC 典型宽度约 **13mm**（BOM v3 第 16 项采购件）。13mm > 12mm，需弯折才能通过。**未验证**（无实物）。
- 建议：实测 FFC 宽度，过槽/穿线孔加宽至 ≥15mm。

### P2-5 盖板 120×160×2mm 薄板翘曲风险
- cover 为 2mm 厚大平板（12 个三角片，体积 38,400mm³）；竖放打印细高易晃，平放打印大平面易翘边。
- 建议：竖放打印加宽裙边；或盖板加 0.5mm 边框筋；或分两半打印再拼接。

### P2-6 云台 M3 安装孔未建模、依赖现场钻孔
- 连接矩阵"平台顶面按支架孔位钻 4×M3 通孔"（`装配验证报告.md` 二·五）；PLA 现场钻孔易开裂。
- 建议：按 SG90 双轴支架实测孔位在 deck 上预建模 φ3.2 孔。

### P2-7 面板打印方向建议与报告不符
- 报告称"面板（75° 倾斜+折边）建议开启支撑"；实际上 75° 是**装配姿态**，打印时应把面板**背面贴床平放**（120×95 面朝下），窗口/过槽/折边均为竖直特征，**无需支撑**。
- 建议：更新打印建议，明确每件的推荐打印方向（lower 开口朝上、spine 竖立、front 背面平放、deck 顶面朝下（销/筋朝上）、cover 竖立）。
