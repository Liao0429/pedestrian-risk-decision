## 一、总体结论

项目**软件与算法部分准备充分**（真实数据、口径标注、双实现黄金回归、真机主链路 7.46 FPS / 28h+ 长稳），文档的「诚实口径」文化在毕设中属于明显加分项。但**答辩展示的硬件闭环（屏幕/语音/云台/LED）尚未完成集成**：截至 2026-10-29 的权威答辩方案（BOM v3 手册 §六）仍将「舵机接入主循环、三色 LED、触摸屏菜单、语音播报」四项标为**需实现**，且 ILI9341 屏幕尚未采购、未点亮（`lvgl_board_port.md` 自述）。而 `README.md` 特性表已把语音告警/双舵机云台/触摸屏菜单列为可用特性——**README 声称能力与答辩方案实际状态存在冲突**，这是答辩现场最可能被评委一击命中的断点。PCB 与 3D 外壳停留在「可打样/几何验证通过」阶段，无实物验证记录。

**风险画像：P0 共 3 项（硬件展示链路未闭环、README 与答辩方案状态冲突、外设采购/联调时间不足）；P1 共 8 项（口径复杂度、统计表述、实时性、无 GT、阈值标定、PCB/外壳无实物、demo 流未验证等）；P2 共 9 项建议。**

### Q3. 一致率到底是多少？98.21%、89.67%、91.3~91.6% 三个数哪个是真的？能现场复现吗？

- **评级**：P1（建议答辩统一采用「共线 + 帧非独立 + 组间差异」表述，并主动给出按视频聚合 ρ=0.23）。
