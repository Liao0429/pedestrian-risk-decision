# Kalman 多目标跟踪代码审查报告

- 审查对象：
  - `src/algorithms/kalman_filter.h`（单目标 CV 模型 Kalman，header-only）
  - `src/luckfox_rtsp_yolov5/src/enhanced_decision.cc`（多目标最近邻关联）
  - 关联头文件：`src/luckfox_rtsp_yolov5/include/enhanced_decision.h`
- 审查方式：只读，不修改代码。对协方差数值稳定性与多目标关联分别做了数值仿真验证。
- 总体结论：**设计合理、可编译、常规参数下数值稳定；主要风险集中在多目标关联的门限机制与少数魔法常量，建议按优先级加固，非必须重构。**

## 一、数值稳定性（kalman_filter.h）

### 1.1 协方差对称性与正定性 —— 低风险，建议换 Joseph 形式

更新方程使用简化形式 `P = (I - K·H)·P`，而非数值更稳健的 Joseph 形式
`P = (I-KH)·P·(I-KH)' + K·R·K'`。理论上后者对称性/正定性保持更好。

数值仿真（双精度，CV 模型，dt=1/30，sigA=1.5，sigZ=0.5，恒速+噪声测量，2000 步）：

```
最大协方差对称性误差：1.39e-17
P 最小特征值（正定性下限）：0.0168  (>0，保持正定)
```

**结论**：本问题条件数良好，双精度下 2000 步对称性误差与 PSD 漂移均可忽略，`P=(I-KH)P` 形式在现参数下不会导致协方差发散。但嵌入式平台若将来改单精度或长时间运行，建议改为 Joseph 形式以彻底消除对称性漂移风险。

### 1.2 mat22Inverse 奇异阈值 —— 阈值不随量纲缩放，理论隐患

`mat22Inverse` 中行列式阈值硬编码为 `1e-12`，且无单位、不与矩阵尺度关联。S = H·P·H' + R，因 R=diag(sigZ²)>0，S 恒正定，理论上不会奇异。

仿真验证（sigZ=0.02 极小噪声）：

```
最小 det(S)：3.61e-7  （仍远高于 1e-12，未触发）
P 最小特征值：1.33e-4
```

**结论**：在文档标注的常规参数（sigZ=0.5）下阈值不会误触发；但阈值是绝对量，若测量噪声量级降至 1e-6 米级或引入极小数尺度，可能把正常矩阵误判为奇异。

### 1.3 奇异时静默降级 —— 无错误标志

当 `mat22Inverse` 判定奇异时返回零矩阵，`K=0`，`correct()` 退化为 no-op（状态与协方差均不更新），但**没有任何错误码/日志/标志位**。表现为"轨迹冻结但系统认为正常"，难以排查。建议增加可观测性（如返回是否退化、或对 det 阈值用相对判据 `det < eps·trace(S)`）。

### 1.4 协方差发散 —— 不会无界发散

Q 为恒定离散白噪声模型，存在稳态协方差，不会无界增长。`init` 的初始 P 取 `(10·sigZ)²` 位置 / `(10·sigA·dt)²` 速度，量级合理。唯一注意点：未匹配轨迹**不调用 predict**，协方差不增长，因此门限也不随丢失帧数扩大（见 2.2）。

### 1.5 dt 固定假设

滤波器使用构造时固定的 `frame_dt`（默认 1/30）。摄像头实际帧率抖动（掉帧/丢帧）会造成运动模型失配。若帧率不稳定，建议每帧实测 dt 并重建 F/Q。

## 二、多目标关联健壮性（enhanced_decision.cc）

### 2.1 关联算法为"最近邻贪心（GNN 近似）"

实现是：生成全部 (轨迹,观测) 候选对，按距离升序排序后**贪心**逐对取用（每轨迹/每观测一次）。这比逐轨迹独立最近邻更好（确定性、全局近似），但**不是全局最优分配**（如匈牙利算法）。行人规模小（几人~几十人）时完全够用；若未来人数增多，建议评估 Hungarian。

### 2.2 门限仅用位置欧氏距离，未用 Mahalanobis/速度预测 —— 主要风险

关联门限 `kalman_gate_m`（默认 2.0 m）是**固定圆形硬门限**，只比较当前轨迹位置 `(kf.x(), kf.y())` 与观测点的欧氏距离：

- **未利用速度预测**：门限中心是"上次修正后的位置"，不是预测位置；轨迹未匹配时也不 predict，状态停留在旧值。
- **未利用协方差**：没有 Mahalanobis 距离，轨迹协方差（含速度不确定度）不参与门限，2 m 内任意观测点都被等同接受。
- **交叉/拥挤场景易误关联**：门限 2.0 m 与图建边距离 `edge_dist_m=2.0` 相同，即"即将在图中相连的行人"恰好处于关联歧义距离内。交叉或密集行走时，两个目标都在彼此门限内，贪心按距离取最近，可能把错误观测喂给某条轨迹，**污染其速度估计并输出抖动的位置点**，进而影响图拉普拉斯特征（density/clustering/fiedler）的稳定性。

数值仿真（两条行人交叉，A 0→4m，B 4→0，噪声 0.15m，门限 2.0m）：

```
轨迹存活：2
交叉后顺序错乱帧数（瞬时 ID 歧义）：2 帧
```

轨迹 ID 最终未永久互换，但交叉瞬间存在 2 帧的关联歧义/抖动。若门限采用"预测位置 + 协方差（Mahalanobis）"或至少用预测位置做门限中心，可显著降低此类抖动。

### 2.3 输出点数恒等于检测点数（去幽灵点设计合理）

匹配轨迹输出平滑位置，未匹配点新建轨迹输出原始观测，`out` 大小恒等于 `np`。因此 `res.n` 恒等于检测数，图特征不会因"幽灵预测点"而失真。这是**好的设计**。代价是暂时丢失的轨迹不会补出预测位置（下游不需要）。

### 2.4 轨迹出生无滞回，易碎片化

误检闪烁（同一目标某帧漏检、下帧出现）会反复触发"旧轨迹 miss+1 → 新建轨迹"，导致短命轨迹碎片、ID 频繁更替。因 ID 不对外输出，影响有限；若未来输出 ID，需加入"轨迹与观测点对多对多再确认"或出生滞回。

### 2.5 轨迹 ID 未输出

`KalmanTrack` 有 `id`，但 `smoothPoints` 只返回坐标，下游拿不到身份。当前用途（仅平滑脚点喂图特征）可接受；若要做跨帧身份跟踪，需暴露 ID 与轨迹元数据。

## 三、参数配置化评估

**已配置化（通过 `EnhancedConfig`，较好）：**

| 参数 | 默认值 | 是否配置化 |
|---|---|---|
| `frame_dt` 帧间隔 | 1/30 | ✅ |
| `kalman_process_noise` (sigA) | 1.5 | ✅ |
| `kalman_measurement_noise` (sigZ) | 0.5 | ✅ |
| `kalman_gate_m` 关联门限 | 2.0 | ✅ |
| `kalman_max_miss` 最大丢失帧 | 5 | ✅ |
| `enable_smoothing` 平滑开关 | true | ✅ |

**未配置化的魔法常量：**

- `mat22Inverse` 行列式阈值 `1e-12`（应改为相对阈值，如 `eps·trace(S)`）
- `init` 初始协方差系数 `10.0`（`10*sigZ`、`10*sigA*dt`）
- `KalmanFilter` 构造默认参数（1.5/0.5）虽存在，但被 `EnhancedConfig` 传入的值覆盖，实际生效的是配置值。

**建议**：关联门限不应是固定 2 m，而应配置为"预期帧间位移 + k·sqrt(协方差)"的自适应量，或至少允许按 `process_noise`/`dt` 推算的门限。当前 2 m 门限在密集场景偏大，容易把不同目标误关联。

## 四、修复建议（按优先级）

| 优先级 | 事项 | 位置 | 建议 |
|---|---|---|---|
| P1 | 门限中心改用预测位置（未匹配轨迹也先 predict），并考虑 Mahalanobis 门限 | enhanced_decision.cc smoothPoints | 在门限计算前对每条轨迹调用 `predict()`，用 `kf.x()` 预测值作为门限中心；进一步可计算 S 做概率门限 |
| P1 | 交叉场景关联歧义 | smoothPoints | 至少利用速度预测区分运动方向；人数多时评估 Hungarian 全局最优 |
| P2 | `mat22Inverse` 阈值改相对判据并暴露退化标志 | kalman_filter.h | `det < eps*(S00+S11)` 替代绝对 `1e-12`；`correct()` 返回是否正常 |
| P2 | `P=(I-KH)P` 改 Joseph 形式 | kalman_filter.h correct() | 消除对称性漂移隐患，为未来单精度/长运行打底 |
| P2 | 帧率自适应 dt | kalman_filter.h / enhanced_decision.cc | 若帧率抖动明显，每帧实测 dt 重建 F/Q |
| P3 | 轨迹出生滞回 / ID 输出 | enhanced_decision.cc | 若未来输出身份，加入确认机制 |
| P3 | 门限与 `edge_dist_m` 解耦 | EnhancedConfig | 提供独立的 `kalman_gate_m` 且默认值应小于建边距离或按运动学推算 |

## 五、验证实验摘要

在 Python 中按 `kalman_filter.h` 的矩阵运算逐位复现，验证：

1. 双精度 2000 步：协方差对称误差 ≤ 1.39e-17，最小特征值 0.0168（正定保持）→ 常规参数下无发散。
2. `sigZ=0.02` 极小噪声：`min det(S)=3.6e-7`，未触发 `1e-12` 阈值 → 阈值误触发仅理论可能。
3. 双目标交叉仿真：门限 2 m 下存在 2 帧关联歧义/输出抖动 → 佐证门限机制的健壮性风险。
