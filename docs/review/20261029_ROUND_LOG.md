### R9~R16 交叉质疑核心结论
- **R9（A1 vs A4）**：错误源在 tracking_servo.md 而非 BOM v2 本身（需修 4 份文档）；BOM v2 位号与 Gerber v1.5 系统性错位（J8/J9~J15/U2 实板不存在），实为"重写手册"；v2 实跑 DRC 7 处短路 → 加强"先打 v1"结论。
- **R10（A2 vs A7）**：7807 在 git 历史 a92e4a5 有存档，【高】应降【中/低】；89.67% 归因错误（生产配置离线回放 98.21%，真实偏差仅 1.8%）；911 帧是实验公式不同（伪问题）；Spearman 构造性需换论证（ρ 源于共线，非同源）。
- **R11（A3 vs A5）**：现有 STL 重做判断准确（三角形级证据）；5 件式可行但件间连接方案缺失；FOV 需显式不等式 + tilt 软件限幅 ±30°；屏幕开窗实际余量仅 1.5mm；SC3336 FFC 长度（15~20cm）不够 30~40cm 路径。
- **R12（A4 vs A8）**：A8 漏报更严重错误——舵机 PWM 引脚整体错位（Pin5/Pin4 应为 Pin7/Pin6）、UART4 /dev/ttyS4 是幻影设备；go2rtc 8080 应降 P1；收敛须以 v1.5 Gerber 位号为唯一事实源重写 BOM v2；内存口径应"常态 9~11MB + 重启瞬时 13.1MB"。
- **R13（A5 vs A2）**：评分倒挂应从 P1 升 **P0**（主链路输出错误，答辩可现场复现）；重复点导致图拉普拉斯饱和是新必现触发源；DBSCAN 测试复刻版哨兵值恰反（-1/-2 颠倒）；Kalman 幽灵点污染消融脚本；A2 修复建议会破坏黄金数据（n_ref=50 使 score 0.81→0.63）。
- **R14（A6 vs A1）**：P1 分级合理不升 P0；现有测试全部无法捕获构建缺陷；A1 修复建议不完整（缺 sample_comm 链接）；Makefile luckfox 目标增量构建失效（不在 .PHONY）；"本机无 g++"与 912 断言通过矛盾需统一。
- **R15（A7 vs A6）**：A6 统计全部正确（191/187+4/912/952 复跑无误）；评分倒挂是系统性现象（DANGER 帧 n≤3 占 45%）；SPI/DBSCAN 应降 P2（非主链路）；CI 门禁一半过度工程；补测优先级：评分校准 > RKNN 注入 > SPI。
- **R16（A8 vs A3）**：RKNN 返回值应升 **P0**（UB 评委一眼可见 + reserve 崩溃路径）；SPI_IOC_MESSAGE(N) 救不了 ILI9341 读 ID（DC 是外部 GPIO）；selftest.md PASS 预期不成立（探测 compatible 而非芯片 ID）；中文注释 8.5/10 偏高；修复须配文档同步清单。
