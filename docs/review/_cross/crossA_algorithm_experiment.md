# 交叉质疑 A：算法与实验争议仲裁报告

仲裁员独立复算（numpy 2.x eigvalsh）、核对消融/场景/基线/标定 JSON 与源码。逐条结论如下。

## 争议 1：L_sym 是否值得做（agent3_review2 纠正 μ₂ 值域）

- 双方观点：前批称归一化拉普拉斯"连通图 μ₂∈(0,1]"；review2 实测 K3=1.5、K4=1.333、K2=2.0，正确值域 (0,2]，且 4 点全分散 μ₂=1.0 污染语义。
- 复算：完全一致。K3=1.5000、K4=1.3333、K8=1.1429、K16=1.0667、K2=2.0000；P5/P10/P20/P30 μ₂=0.293/0.060/0.014/0.006；两簇 K4 相距 5m μ₂=0；4 点全分散 L_sym=I，μ₂=1.0。λ₂/λmax：K_n=1，P5→P30=0.106→0.003，全分散=0/0(NaN)。
- 仲裁结论：**支持 review2 的纠正**，前批 (0,1] 说法错误。接入 FSM 前两者都不稳：μ₂ 在全分散/孤立点场景取 1.0，直接污染 SAFE 类；λ₂/λmax 需 0/0→0 守卫且随链长衰减。若必须二选一，带守卫的 λ₂/λmax（0=不连通、1=完全图）比 μ₂ 更安全。Jacobi O(n³) 在 n<30 时不是障碍（n=30×100 sweep≈2.7M 次运算，相对 145ms 帧预算可忽略）；真正障碍是 max_sweeps=100 对 P10+ 长链不收敛→静默回退 0（graph_laplacian.h:163-176,300-305），以及谱语义本身不可靠。

## 争议 2：消融 B==C 的含义（"未接入"还是"无效"）

- 双方观点：agent3/4/6 称谱特征零贡献；但 C 组 use_spectral 仅把谱值放入 feat 字典，FSM/规则输入仍只有 n/density/r_gcc。
- 复算：ablation_study.py:72-84 —— `feat` 含谱值但从未被消费；`fsm.update()` 与 `rule_level()` 只用 n/density/r_gcc。B==C 是设计使然，6/6 视频逐位相同。
- 仲裁结论：**B==C 证明"未接入"，不证明"谱特征无效"**。agent4/6 的准确表述（"对决策零贡献/物理上不可能影响输出"）成立；凡暗示"谱特征本身无用"的表述均属过度推断。要证明无效/有效，需把归一化谱特征（如带守卫的 λ₂/λmax 或 μ₂）真正作为 FSM 第 4 维输入、重跑消融并给出等级分布变化与链/团区分度。

## 争议 3：FSM 与规则阈值语义漂移

- 复算：scenario_test.json 确认双向分歧——n8_cluster（0.8m 网格）规则 WARNING、FSM DANGER（score=0.4·0.4+0.3·0.964+0.3·1≈0.749）；n10_chain（1.5m 链）规则 DANGER（gcc=1）、FSM WARNING（score=0.56）。
- 仲裁结论：**双标准必然分歧，非 bug 也非"特性"，而是必须文档化的系统行为**。规则是硬 AND 门限，FSM 是加权软评分+滞回+确认帧，边界场景天然不一致。论文必须声明 FSM 为唯一决策源、规则仅作对照，且不得再用规则标签作为 FSM 标定/评估的真值（见争议 5）。

## 争议 4：基线 OR→AND 修正的影响

- 复算：真实引擎（crowd_test.py:235-247、risk_engine.cc:104-111）均为 AND；旧基线脚本用 OR，失真。AND 修正后已重跑 111 条：base_sw=2578（均 23.2）、DANGER 帧=2190、DANGER 视频=24；增强侧 sw=444（均 4.0）、DANGER 帧=7807、40 视频。
- 仲裁结论：**"增强后 DANGER -64%"（21969→7807）完全建立在失真 OR 基线上，必须撤回**。公平基线下 DANGER 帧反而 +256%（2190→7807）、DANGER 视频 24→40；切换次数降幅仍约 83%（23.2→4.0）。论文只能声称"稳定性提升 + 报警覆盖变化"，无 GT 不得声称更准/更少误报。`_comparison_summary.json` 仍存旧 OR 数字（base_sw=5147），需由新 `video_baseline/_summary.json` 重新生成并更新 README/fig3。

## 争议 5：阈值标定反例是否成立（agent6）

- 复算：results/baseline/results.json（30 图：SAFE 23/WARN 5/DANGER 2）复算得分：SAFE 最高 0.660>up_danger 0.65；WARNING 0.515~0.660（文档写 0.62~0.66，错误）；DANGER 0.675~0.679；4/23 SAFE≥0.40。agent6 数字全部可复现。
- 反例推理审查：①30 图/2 DANGER 样本量确实不足以标定；②不是"0.01 余量"，而是 SAFE 最高分已越界 0.01；③FSM 确认帧只滤瞬态尖峰，对持续静止的 3 人紧簇场景（0.3s 后升级）无效；④关键：该"SAFE"是规则引擎输出（该图 GT=13 人仅检出 3 人→n<5 判 SAFE），非真值，反例本质是"规则与 FSM 双标准分歧被漏检放大"，不能单独作为"标定不可信"的充分证据。
- 仲裁结论：**部分支持 agent6**——标定集过小、类别重叠、文档区间错误三项成立，应扩大标定集、用 GT 而非规则标签、补敏感性分析；但"SAFE 0.66 必误报"的表述需弱化为"双标准分歧+漏检"案例。

## 汇总

- 支持 review2（μ₂ 值域/语义缺陷）、支持 agent4/6 的"未接入"事实与 OR 基线批评；反对"谱特征无效"的过度推断；标定批评成立但反例需重新定性。
- 最高优先级整改：①重生成 `_comparison_summary.json` 并改写 README 对比结论；②修复消融 C 组（真正接入谱特征或删除）；③论文明确 FSM 唯一决策源、规则仅对照。
