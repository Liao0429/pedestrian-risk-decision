## 二、与已有工作的区别

- 多数人群分析工作以「密度图回归/人群计数」为核心（LCDnet 等），需要专用训练数据；
  本项目以**检测计数 + 图论拓扑特征**（密度/连通分量/聚类系数/谱特征）刻画聚集结构，
  无需训练、可解释性强，更适合 1TOPS 边缘端。
- 多数边缘部署工作只做到「检测上板」；本项目额外实现了 **IPM 米制坐标 + 图特征 + FSM 时序风险决策** 的完整链路。
- **诚实定位**：上述组合是「工程集成创新」，不是算法原创。论文应表述为
  「面向 RV1106 的检测-几何-图论-时序轻量化风险决策流水线的设计与实现」，
  不得宣称「提出新的谱聚类算法」或「谱特征提升准确性」（当前谱特征未接入决策，无证据）。

## 三、候选改进方向（按证据强度排序）

### 方向 A：把归一化谱特征真正接入 FSM，用消融验证收益（P1 实验，有理论依据）

1. **问题**：当前谱特征（fiedler/谱半径/特征熵）只计算并显示，未进入 FSM score；
   消融 C 组=B 组是因为「未接入」而非「无效」（交叉仲裁 crossA 结论）。
2. **原理**：用**相对代数连通度** `fiedler / spectral_radius`（∈[0,1]，跨规模可比）或归一化拉普拉斯
   L_sym 的第二小特征值（连通图 ∈(0,2]，值域跨规模稳定）作为 FSM 的第四个输入（或替换 r_gcc 的一部分权重）。
3. **预期收益**：若谱特征能区分「链状连通」（当前 gcc=1 误判 DANGER）与「团状聚集」，可修正场景实验暴露的
   规则引擎局限（n10_chain 规则 DANGER）。
4. **成本**：Jacobi O(n³) 每帧已计算（n<30 时亚毫秒~毫秒级，交叉仲裁确认非瓶颈）；改动集中在
   `graph_laplacian.{py,h}` 增加归一化特征 + `risk_fsm` 权重配置 + C++/Python 黄金回归更新。
5. **验证**：消融 C vs B 必须产生差异；场景测试中 chain 场景等级应不同于 cluster；111 条视频重跑对比稳定性。
6. **回退**：FSM 权重可配置，归一化特征作为可选项（默认关闭），不改配置即回退旧行为。

### 方向 B：图片 500 张风险等级人工标注（P0 实验数据，低成本高说服力）

1. **问题**：无 GT 导致「准确率/误报率/漏报率」全部不可算，论文只能报稳定性。
2. **方案**：500 张图按整体风险标 SAFE/WARNING/DANGER（约 2h），双人标注 + Cohen's Kappa>0.6。
3. **预期收益**：可计算 3×3 混淆矩阵、各类别召回、误报率；论文实验章节从「检出率」升级为「风险分级准确率」。
4. **成本**：人工 2h（图片）；视频抽帧 3000 帧约 12-18h（可选）。
5. **验证**：Kappa>0.6 后，用系统输出 vs GT 计算指标；若 Kappa 不足，只报告一致性分析。
6. **风险**：无——纯标注，不改算法。

### 方向 C：主循环耗时打点 + 检测降频/双缓冲（P1 工程，有理论依据）

1. **问题**：板端 6FPS 瓶颈是单线程串行 + 软件预处理（cvtColor/resize/letterbox/putText），
   -O2 无提升证明瓶颈不在编译优化（Agent2/5/交叉C 一致）。
2. **方案**：在主循环各阶段加 monotonic 时钟打点（VI 取帧/RKNN 推理/cvtColor/letterbox/图特征/VENC），
   输出到日志；根据打点结果决定：检测每 2 帧一次（推理减半）、或 RKNN 与 VENC 双缓冲解耦。
3. **预期收益**：帧率从 6FPS 提升到 8-12FPS（估计），现场演示更流畅。
4. **成本**：代码低；真机验证需要开发板（待办）。
5. **验证**：打点日志明确各阶段 ms 分布；改动前后帧率对比（基线 6FPS）。
6. **回退**：打点代码用宏/配置开关，默认关。

### 方向 D（研究假设，暂不实施）：DBSCAN 聚类接入决策

- 当前 DBSCAN（eps=1.5, min_samples=2）与图建边阈值 2.0 语义冲突，且 min_samples=2 退化为连通分量
  （Agent3 数值实验）。若接入，需先统一阈值语义（eps=2.0 或明确物理含义）并做单变量分析。
- **暂缓**：收益不确定、与 r_gcc 高度重复；列为 P2。
