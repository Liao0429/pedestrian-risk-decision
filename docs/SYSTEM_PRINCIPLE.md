# 系统实现原理与算法详解

> ：《基于 C++ 的边缘端轻量化行人感知与风险决策软件系统设计》
> 平台：Luckfox Pico Max（RV1106，单核 1.2GHz，256MB，1TOPS NPU）

## 一、系统总览

### 1.1 系统目标
在低算力边缘设备上，实时检测画面中的行人，分析人群的空间分布与聚集程度，并自动输出 **SAFE / WARNING / DANGER** 风险等级，实现主动预警。

### 1.2 整体数据流（算法流水线）
```
摄像头视频帧
 │
 ▼
[1. 感知] YOLOv5n + INT8 量化 ──► 行人边界框(bbox) + 置信度
 │
 ▼
[2. 几何] IPM 逆透视映射 ──► 脚点像素坐标 → 地面米制坐标(Xw,Yw)
 │
 ▼
[3. 拓扑] 邻接矩阵 + 图拉普拉斯 + DBSCAN ──► 网络特征(密度/连通分量/簇数/谱特征)
 │
 ▼
[4. 时序] Kalman/ByteTrack 跟踪 + EMA 平滑 ──► 平滑轨迹 + 稳定特征
 │
 ▼
[5. 决策] FSM 有限状态机(滞回) ──► SAFE / WARNING / DANGER
 │
 ▼
[6. 输出] 画面叠加 + RTSP 推流 + (语音告警/大屏/舵机)
```

### 1.3 架构特点
- **前端轻量化感知 + 几何空间校正 + 图论拓扑分析 + 时序风险决策** 的复合流水线
- 各模块解耦，可单独升级（基础版 → ByteTrack/DBSCAN 升级版）

## 二、各算法模块详解

### 2.1 轻量化目标检测算法（Perception）

**原理**：
- YOLOv5n 是一阶段目标检测器：把输入图像划分为 S×S 网格，每个网格直接预测多个候选框的类别和位置（无需两阶段区域提议）。
- **INT8 量化**：把模型权重和激活从 FP32（32位浮点）量化为 INT8（8位整数），配合 RV1106 的 NPU 硬件加速，把乘加运算从浮点变定点，大幅提速并降低内存。

**功能**：
- 对每帧画面输出所有行人的边界框 `(x1,y1,x2,y2)` 和置信度 `conf`。
- 只保留 person 类别（COCO 第 0 类）。

**用处**：
- 是整个系统"感知"的地基——后续所有几何、拓扑、决策都依赖"哪里有人"。
- 轻量 + 量化，保证在 1TOPS NPU 上实时（几十 FPS）。

### 2.2 空间几何投影与坐标转换算法（IPM）

**原理**：
- 摄像头斜装俯视，画面存在"近大远小"透视畸变：同样 1 米的地面距离，在画面底部（近处）占很多像素，在顶部（远处）占很少像素。
- **逆透视映射（IPM）**：通过单应矩阵 H（3×3），把图像像素坐标 `p=[u,v,1]` 映射到地面平面坐标 `P=[X,Y,1]`，满足 `sP = H·p`。
- H 可由 4 组"像素点↔地面点"对应解出（真机标定用 `cv::getPerspectiveTransform` / `findHomography`）。

**功能**：
- 把每个检测框的**底部中心点（脚点）**从像素坐标转换为**真实地面米制坐标 (Xw, Yw)**。

**用处**：
- 让"行人之间的距离"变成真实物理距离（米），而不是受透视影响的像素距离。
- 是后续**建边（2m 阈值）、DBSCAN 聚类、密度计算**的准确性根基。
- 手填 H 只是近似；**真机标定**（升级）能把它变成厘米级准确。

### 2.3 图论空间拓扑与聚类算法（Topology & Clustering）

#### 2.3.1 邻接矩阵与图拉普拉斯
**原理**：
- 把每名行人看作图的一个**节点**。
- 若两行人地面距离 < 阈值 R（如 2.0m），则在两节点间建一条**边**，得到邻接矩阵 A。
- 定义度矩阵 D（对角元为每个节点的度数），构造**图拉普拉斯矩阵 L = D − A**。
- 对 L 做特征分解，得到特征值 λ1≤λ2≤…≤λn：
 - **代数连通度**（第二小特征值 λ2，又称 Fiedler 值）：反映整体连通/聚集程度，越大越"紧密"。
 - **谱半径**（最大特征值）：反映图中连接强度的上界。
 - 特征值分布（谱熵）可刻画人群结构是"松散还是模块化"。

**功能**：
- 输出：网络密度、边数、最大连通分量占比、聚类系数、Fiedler 值、谱半径等。
- 刻画人群"局部聚集 / 整体连通"的空间结构。

**用处**：
- 核心创新点：**区分"人数多但分散"与"人数相同但局部聚集"**。
 - 10 人分散在广场 → 边少、Fiedler 值低 → 未必危险。
 - 6 人挤在门口 → 全连通、Fiedler 值高 → 判 WARNING/DANGER。

#### 2.3.2 DBSCAN 人群聚类（升级）
**原理**：
- DBSCAN 是基于密度的聚类：给定半径 ε 和最少点数 minPts，把"密度相连"的点聚成一簇，并标记噪声点。
- 复杂度 O(n log n)（用空间索引）。

**功能**：
- 直接输出**人群簇**：簇数、每簇人数、簇中心、最大簇人数占比。
- 天然识别"局部聚集的小团体"。

**用处**：
- 比谱特征更直观、更快，适合工程化决策；与拉普拉斯谱互补（一个讲理论深度，一个讲工程实用）。

### 2.4 时序状态估计与风险决策算法

#### 2.4.1 Kalman 滤波（基础版）
**原理**：
- 线性匀速（CV）模型：状态 `x=[x,y,vx,vy]`（位置+速度），观测 `z=[x,y]`。
- 两步循环：
 1. **预测**：`x̂ = F·x + 噪声`，先验协方差更新。
 2. **更新**：用观测 z 修正，得到后验状态（融合预测与观测，按卡尔曼增益加权）。
- 结果：对目标位置/速度的最优估计，**平滑噪声、补漏检**（预测框可在检测缺失时续上）。

**功能**：追踪每个行人的地面坐标轨迹，输出平滑位置和速度向量。

**用处**：解决单帧抖动、短时遮挡漏检，为速度异常判断提供依据。

#### 2.4.2 ByteTrack 多目标跟踪（升级）
**原理**：
- 每个目标维护一个 Kalman 滤波器（预测下一帧位置）。
- 检测框与预测框做 **IoU 关联**；高置信度框先匹配，**低分框做二次关联**（恢复被遮挡目标）。
- 维护 track ID，丢失超过 N 帧才删除。

**功能**：多目标跟踪，稳定输出每个行人的 ID、轨迹、速度，支持跨帧关联。

**用处**：比单目标 Kalman 强很多——能处理多人交叉、遮挡、ID 漂移，为"滞留时间、速度异常、聚集度时序统计"提供可靠基础。

#### 2.4.3 EMA 时序平滑（升级）
**原理**：对特征序列做指数滑动平均 `s_t = α·x_t + (1−α)·s_{t−1}`，α∈(0,1)。
**功能**：平滑人数/密度/Fiedler 值等输入特征，抑制单帧噪声。
**用处**：降低误报，让 FSM 输入更稳定。

#### 2.4.4 FSM 有限状态机决策
**原理**：
- 状态集合：`{SAFE, WARNING, DANGER}`。
- 输入：综合特征（归一化人数 + 密度 + 聚集度 + 运动趋势）计算拥挤度评分。
- 状态迁移带**滞回**（进入 DANGER 需评分>高阈值，回到 WARNING 需评分<低阈值）和**保持时间**（连续 N 帧才升级），防止抖振。

**功能**：把连续评分映射为离散、稳定的安全等级。

**用处**：
- 决策层：输出最终可执行的告警等级。
- 滞回+保持时间，避免"一帧噪声就误报/闪跳"，提升系统可靠性（重点）。

## 三、算法用处总结表

| 算法 | 解决的问题 | 输出 | 对准确度/效率的贡献 |
|---|---|---|---|
| YOLOv5n+INT8 | 边缘端实时检测 | 行人框+置信度 | 速度↑↑（NPU定点），精度可接受 |
| IPM | 透视畸变 | 地面米坐标 | 距离准确度↑↑（真机标定） |
| 邻接矩阵+拉普拉斯 | 空间结构刻画 | 密度/连通/Fiedler | 区分"分散vs聚集"（创新点） |
| DBSCAN | 局部聚集识别 | 人群簇 | 聚类直观、O(n log n)快 |
| Kalman | 轨迹噪声/漏检 | 平滑轨迹+速度 | 时序稳定↑ |
| ByteTrack | 多人跟踪 | 稳定 ID/轨迹 | 遮挡处理、跟踪鲁棒性↑↑ |
| EMA | 特征抖动 | 平滑特征 | 决策稳定↑ |
| FSM | 等级判定 | SAFE/WARNING/DANGER | 防抖、可解释 |

## 四、一句话概括
> "本系统采用'前端轻量化感知 + 几何空间校正 + 图论拓扑分析 + 时序风险决策'的复合算法流水线：量化 YOLOv5n 提取行人空间特征，逆透视变换消除畸变，图拉普拉斯/DBSCAN 刻画人群聚集结构，Kalman/ByteTrack 时序滤波，FSM 实现稳定可靠的风险分级预警。"
