# WORKLOG 2026-10-30：基准版本锁定

## 背景
10月30日全天排查"画面模糊/横幅撕裂"问题，尝试了多种编码参数组合（CBR/GOP/FIXQP/帧率字段/中文字库/memset等），均未解决。用户最终要求回退到10月26日原版。

## 根因（已查明但修复引入新问题）
VENC 输出帧根据大小拆分为多个 pack（`stFrame.u32PackCount > 1`）。原代码只发送 `pstPack[0]`（第一个pack），后半段数据丢失 → 解码器错误隐藏 → 画面前半段清晰、后半段撕裂。
