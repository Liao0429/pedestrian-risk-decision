# 消融实验报告（Ablation Study）

> 目的：量化"增强决策"各组件（Kalman 跟踪平滑 / 图拉普拉斯谱特征 / FSM 时序决策）对系统稳定性的贡献。
> 方法：6 条代表性真实视频（Mixkit，覆盖密集/过渡/稀疏场景），逐步叠加组件，统计**等级切换次数**（越低越稳定）。
> 数据：`results/rerun/_ablation.json`，全部真实运行，可复现（`scripts/ablation_study.py`）。

## 1. 配置组合

| 组 | Kalman | 谱特征 | FSM | 说明 |
|---|---|---|---|---|
| A 基线 | ✗ | ✗ | ✗ | 逐帧检测 + 阈值规则判定（无时序平滑） |
| B +Kalman | ✓ | ✗ | ✗ | 加多目标跟踪平滑脚点 |
| C +Kalman+谱特征 | ✓ | ✓ | ✗ | 再加图拉普拉斯谱特征（不启用 FSM） |
| D 完整增强 | ✓ | ✓ | ✓ | 完整系统（含 FSM 滞回/保持） |

## 2. 结果（等级切换次数）

| 视频 | 帧数 | A 基线 | B +Kalman | C +Kalman+谱特征 | D 完整增强 |
|---|---|---|---|---|---|
| mixkit_134（人群过渡） | 600 | 27 | 16 | 16 | **10** |
| mixkit_13192（密集） | 305 | 18 | 4 | 4 | **4** |
| mixkit_3428（高密集） | 456 | 2 | 0 | 0 | **2** |
| mixkit_4519（高密集） | 603 | 0 | 0 | 0 | **2** |
| mixkit_4178（中等密集） | 298 | **154** | 45 | 45 | **6** |
| mixkit_50134（稀疏） | 388 | 10 | 5 | 5 | **0** |
| **平均** | | **35.2** | **11.7** | **11.7** | **4.0** |

![消融实验](docs/figures/fig_ablation.png)

## 3. 结论（各组件贡献）

- **Kalman 跟踪平滑（A→B）**：平均切换从 35.2 → 11.7，**降幅约 67%**。最显著（如 mixkit_4178 从 154 → 45），说明跟踪平滑有效抑制了单帧检测抖动导致的等级闪跳。
- **谱特征（B→C）**：在本组"切换次数"指标上贡献不明显（数值相同）。谱特征的主要价值是**风险语义更准确**（引入连通强度 λ₂，可区分"人数少但高度聚集"与"人数多但分散"），而非降低切换；其对误报/召回的影响可结合 COMPARISON 的 DANGER 帧统计理解。
- **FSM 时序决策（C→D）**：平均切换 11.7 → 4.0，进一步下降（如 mixkit_4178 45 → 6，mixkit_50134 5 → 0）。FSM 的滞回/保持机制消除了瞬时聚集误报，使输出稳定。
- **完整增强（D）**：在所有视频上切换次数达到最低或接近最低（2~10 次），系统输出稳定、可演示。

> 说明：mixkit_4519/3428 基线即几乎稳定（A 组切换 0~2），D 组的 2 次切换来自 FSM 引入了合理的 SAFE/WARNING 状态（如 3428 从"恒 DANGER"变为 DANGER 451/WARNING 3/SAFE 2，语义更真实），属于合理行为而非退化。

## 4. 论文使用建议

- 用本表作为"消融实验"章节主表，强调 **Kalman 解决单帧抖动、FSM 解决瞬时误报、谱特征提升风险语义准确性**。
- 可配合 `docs/COMPARISON.md` 的误报/召回数据形成完整论证链。
