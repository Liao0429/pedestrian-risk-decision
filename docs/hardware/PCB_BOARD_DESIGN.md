# 嘉立创 PCB 底板设计规格书（v1.0）

> ⚠ **2026-10-30 实测校准（hardware-hw / task-3）**：本文档部分引脚/方案与真机实测冲突。
> **引脚与总线请以 [`pin_map_verified.md`](./pin_map_verified.md) 为唯一事实源**；
> 交叉验证结论见 [`docs/review/20261030_round3/hardware_pcb_consistency.md`](../review/20261030_round3/hardware_pcb_consistency.md)。
>
> 具体冲突：本文 §四 网络表是 **v1.0 设计意图**，与**已打样 Gerber v1.7** 有差异：
> Gerber 实际还有 J11（ILI9341 SPI 8P）、J5/J6/J7 为预留、J10A/J10B 跳线区；
> 且 Gerber 上 **5V_SERVO 与 5V 不连通**（舵机轨无电源，必须飞线 J2a-1→J2b-1）、**无覆铜**、
> 丝印 J10A 标注步进 5.08mm 而焊盘 2.54mm（错位）。详见评审报告。

> 用途：为 Luckfox 行人感知与风险决策系统制作一块**底板转接板**，把开发板、双舵机、语音模块、串口屏、电源、开关统一接到一块 PCB 上，插上即可**完全自主运行**。用嘉立创EDA（免费）画图 → 嘉立创下单打样 → 焊接排母/排针/元件 → 插上模块 → 上电。

## 一、整体方案

- **开发板**：Luckfox Pico Max（40pin 排针）以**排母**直插在 PCB 上（或排针/排母互插）
- **底板**：PCB 上布好电源轨、信号走线、模块排针/接线端子
- **外设**：2×SG90 舵机、DFPlayer Mini 语音模块+喇叭、串口屏（USART HMI）、电源开关、功能开关
- **供电**：5V/3A 适配器 → PCB 电源端子 → 分两路（开发板 5V、舵机/语音独立 5V 轨）

## 二、板框建议

- 尺寸：约 **100mm × 80mm**（10×8cm，嘉立创打样经济尺寸）
- 4 个 M3 螺丝孔（四角，距边 5mm）
- 顶层放开发板排母（居左），右侧/下方放外设排针与接线端子
- 两层板，1.6mm 厚，FR-4，绿油白字

| 位号 | 元件 | 封装 | 数量 | 说明 |
|---|---|---|---|---|

## 四、网络连接表（Netlist）

以下为 PCB 上需要连通的所有网络。**开发板引脚以板面丝印和 `/sys/class/pwm`、`/dev/ttyS*` 实际节点为准**，打样前请用开发板实测确认。

### 电源网络
| 网络 | 连接 |
|---|---|
| VIN_5V | J1 输入(+) → SW1 → 分两路：① 开发板 USB-C（经 J2 输出）② 舵机轨 VCC_5V_SERVO |
| VCC_5V_SERVO | 舵机 J3/J4 的 VCC、DFPlayer J5 VCC、串口屏 J6 VCC、C1+ / C2+ |
| GND | J1(-)、所有模块 GND、C1- / C2-、开发板 GND 排针 → 共地 |
| VCC_3V3（可选） | 开发板 3.3V 排针 → 串口屏逻辑（若串口屏 3.3V 电平） |

### 信号网络（开发板排针侧）
| 网络 | 开发板侧 | 外设侧 | 说明 |
|---|---|---|---|
| PWM_PAN（Yaw） | GPIO1_C4_d（PWM8_M1，脚5） | J3 SIG | SG90 水平舵机 |
| PWM_TILT（Pitch） | GPIO1_C5_d（PWM9_M1，脚4） | J4 SIG | SG90 俯仰舵机 |
| UART_TX_VOICE | 板 TX（UART4，如 GPIO1_B1_d） | J5 RX | 板→DFPlayer |
| UART_RX_VOICE | 板 RX（UART4，如 GPIO1_B0_d） | J5 TX | DFPlayer→板 |
| UART_TX_SCREEN | 板 TX（UART3，待核对引脚） | J6 RX | 板→串口屏 |
| UART_RX_SCREEN | 板 RX（UART3，待核对引脚） | J6 TX | 串口屏→板 |
| GPIO_SW_ALARM | GPIO（如 GPIO1_C3_d，脚92体系/实际） | J8 | 功能开关（10kΩ 下拉到 GND） |

> ⚠️ **打样前必须用开发板实测确认**：`cat /sys/kernel/debug/gpio` 或 `ls /sys/class/pwm`、`ls /dev/ttyS*`、`i2cdetect` 确认 PWM 通道、UART 设备号、GPIO 编号。串口屏与语音各占一个 UART，不要冲突。

## 五、嘉立创EDA 画图步骤（免费）

1. 注册/登录 **嘉立创EDA（lcsc.com → 嘉立创EDA）**，新建工程「PedestrianRiskBoard」。
2. **画原理图**：按上面位号表放置元件（搜索封装，如 `2.54mm 40P 排母`、`0805`、`5.08mm 端子`、`SG90 三针`、`DFPlayer`）。按网络表连线。
3. **设计 PCB**：原理图画好后点「转为 PCB」，摆放元件（开发板排母 U1 居中，外设排针在四周，电容靠近舵机轨）。
4. **布线**：电源线加宽（≥1mm），信号线 0.3~0.5mm；GND 铺铜。
5. **覆铜/丝印**：顶层铺 GND 铜，标注各接口文字（PAN/PITCH/VOICE/SCREEN/PWR）。
6. **检查 & 下单**：DRC 检查通过 → 「下单」→ 选嘉立创打样（经济型 5 片 10×8cm 约 ¥20-30，1.6mm 绿油）。约 3~5 天寄到。

## 六、焊接与组装步骤

1. **焊排母**：把 40pin 排母焊到 PCB 的 U1 位置（朝上），用于插开发板。
2. **焊排针/端子**：焊 J3~J8、电源端子、SW1。
3. **焊电容/电阻**：C1 电解电容注意正负极（长脚为正接 5V）、C2、R1。
4. **插模块**：开发板插入排母；舵机三针插 J3/J4；DFPlayer 插 J5，喇叭接 J7；串口屏线接 J6。
5. **供电**：5V/3A 适配器 → J1 → SW1 打开 → 开发板上电自启动。
6. **上电自启**：把编译好的程序设为开机自启（systemd 服务或 /etc/rc.local），插电即完全自主运行。
