# 硬件扩展方案（答辩现场版）

> 针对 Luckfox Pico Max（RV1106）毕设系统的完整交互升级。
> 功能：彩色触摸屏动画菜单 + 语音交互（识别+回复）+ 危险语音提醒 + 双舵机云台跟踪 + 三色灯 + 按键 + 无线网络 + 移动供电。

## 1. 系统架构

```
充电宝 → DC电源模块 → 开发板 / 舵机 / 屏幕
开发板 → 屏幕(SPI+LVGL) / 舵机(PWM) / 三色灯(GPIO) / 按键(GPIO) / USB设备(HUB)
语音：麦克风(USB) → sherpa-onnx ASR → 逻辑 → TTS → 喇叭(USB)
危险：检测DANGER → 红灯 + 语音提醒
网络：USB WiFi(连热点) → RTSP 无线推流
```

接线图见 `docs/hardware/wiring_3d.png`（立体图），双舵机云台结构见 `docs/hardware/gimbal_3d.png`。

## 2. 双舵机云台（两个 SG90 跟踪）

```
底座 → 水平舵机SG90①(左右/Yaw) → L型臂 → 垂直舵机SG90②(上下/Pitch) → 摄像头固定座 → 摄像头
```

- 水平舵机控制左右转头，垂直舵机控制上下俯仰，实现目标跟踪。
- 摄像头用**加长 FFC 排线**（15pin 0.5mm 反向，20~30cm）连到开发板，开发板固定不动、摄像头随云台转。
- 舵机 5V 独立供电（与板共地）；排线从云台旋转轴附近走，留余量防缠绕。

## 3. 语音交互（本地离线）

- 输入：USB 麦克风 → sherpa-onnx（ASR 中文命令词："开启检测/关闭检测/返回菜单/现在什么情况"）
- 输出：sherpa-onnx TTS → USB 小喇叭播放语音回复
- 危险联动：DANGER → TTS 播报"危险！人群过度聚集，请立即疏散！" + 红灯亮
- 全离线免费，RV1106（armv7）可运行。

## 4. 屏幕动画菜单（LVGL）

- ILI9341 320×240 触摸屏（SPI + XPT2046），LVGL 图形库。
- 主菜单：标题动画 + 图标 + 参数栏（IP/CPU/内存/帧率，每 500ms 刷新）。
- 语音/按键进入检测：显示摄像头缩略图 + 检测框 + 风险等级。
- 按键（上/下/确定/返回）导航，返回键回主菜单。

## 5. DC 电源模块（充电宝 → 各设备）

```
充电宝 5V/2.4A
  ├─► DC模块①(MP1584调5V) ──► 开发板 GPIO 5V / 舵机
  ├─► DC模块②(MP1584调3.3V) ──► 屏幕 / 逻辑
  GND 全部共地
```

- 舵机独立 5V（防电流波动死机）；开发板经 GPIO 5V 引脚供电（或 Micro USB）。
- 电源端子/Type-C 母座焊在 PCB 上接充电宝。

## 6. PCB 底板（只焊母座 + 模块直插）

PCB 只焊接母座/端子 + 走线，模块全部直插可拔：
40pin 排母(插开发板) / MP1584模块母座×2 / 舵机3P座×2 / LED 3P座×3 / 按键2P座×4 / USB-A母座 / 电源端子 / 屏幕排座。
优点：焊接量小、可插拔维护、外观整洁、答辩可演示拔插。

## 8. 答辩演示流程（60秒）

1. 上电自动启动 → 动画主菜单（IP/CPU/内存/帧率）
2. 语音"开启检测" → 进入检测界面
3. 屏幕显示摄像头画面+检测框+风险等级，三色灯同步
4. 挥手触发 DANGER → 红灯亮 + 语音"危险！人群过度聚集！"
5. 说"现在什么情况" → 系统语音回复当前状态
6. 手机连热点打开 RTSP 看实时画面（无线能力）
